QR codes that stay editable after you print them.

QRDock is a self-hosted QR generator where every code is a short link you control. Print it, then change the destination whenever you want — no reprint, no subscription, no account wall.

Get the code (MIT) Live demo & shop

Why

  • Retargetable: change a printed code's destination anytime — the QR never goes stale
  • Scan analytics: per-link counts and a 14-day chart
  • PNG + SVG export, plus an instant anonymous endpoint /qr.png?text=...
  • Tiny: Python + FastAPI + SQLite, ~50 MB RAM, one docker run
  • MIT: read it, audit it, change it, ship it

Deploy in one command

docker build -t qrdock .
docker run -d -p 8000:8000 -v qrdock-data:/data qrdock

Open http://localhost:8000, register, create a link, print the QR — retarget it forever.
